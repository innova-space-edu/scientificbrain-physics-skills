# Skill card: physics-literature

- Status: v0.3.0
- Purpose: physics-specific literature discovery, deduplication, regime tagging and claim provenance.
- Sources: arXiv, OpenAlex, DOI/publisher metadata and project-provided sources through ScientificBrain.
- Outputs: literature/evidence map, versions, contradictions, regime limits and gaps.
- Non-goal: ranking papers by citation count or accepting metadata/abstracts as proof of detailed claims.
- Security/operations: API credentials and rate limits remain in ScientificBrain connectors, not in the skill.
